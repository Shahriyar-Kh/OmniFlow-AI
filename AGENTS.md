# Durable project rules

- Keep the local foundation at zero monthly software cost.
- Use official platform APIs only; never automate browser logins or scrape social accounts.
- Require human approval before every public publish.
- Never commit credentials, access tokens, `.env`, generated media, or ordinary backups.
- Prefer Windows-first commands and `py -3.13` for host Python instructions.
- Keep the application on Python 3.13.
- Every publish operation must use a unique idempotency key.
- Every approval must reference an exact immutable content version.
- Store timestamps in UTC; interpret editorial schedules in `Asia/Karachi`.
- Preserve existing user files and unrelated changes.
- Run applicable tests and report actual results before declaring a phase complete.
